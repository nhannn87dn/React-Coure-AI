## Repository purpose

This is a Vietnamese-language React JS course curriculum — not a software project. There is no application code, package.json, or build tooling in this repo. The content is course material: lesson outlines and full lesson write-ups (concepts, code snippets as teaching examples, and homework assignments) that walk a beginner through React from ES6+ fundamentals to deployment.

## Structure

- `outline-claude.md` — a alternate high-level outlines (headings only) for the full 12-lesson course, generated by different sources. These are reference/planning documents, not published content.
- `01.Lessons/NN.Lesson-NN-<topic>/` — one directory per lesson, numbered 01–12, matching the outline topics:
  1. Intro React & ESNext review
  2. JSX & Components
  3. Props
  4. State & Event Handling
  5. Conditional Rendering & Render Lists
  6. useEffect & Lifecycle
  7. Forms & Custom Hooks
  8. React Router
  9. Global State (Zustand)
  10. Data Fetching Basic (Fetch/Axios)
  11. Data Fetching Advanced (TanStack Query)
  12. Deploy to Production (Vercel)

Each lesson directory contains:
  - `README.md` — the full lesson content in Vietnamese (all 12 lessons are written; the closing `🧪 Bài tập Homework` section is still empty in lessons 02–12)
  - `assets/` — images referenced by the lesson README (e.g. diagrams), present only where the lesson has images
  - `homework*.md` — homework assignments tied to that lesson (only lesson 01 has content; lesson 02's `homeworks.md` is an empty placeholder)

## Working with lesson content

- Lesson READMEs follow a consistent internal structure: a `🎯 Mục tiêu` (goal) callout at the top, numbered `## Phần N` sections mirroring the corresponding `### ✨` topic in `outline-claude.md`, inline `jsx`/`javascript` code blocks as teaching examples (not meant to compile/run as-is), and a closing `🧪 Bài tập thực hành cuối buổi` (in-class exercise) section, sometimes followed by a `🧪 Bài tập Homework` section linking out to a separate homework file.
- When writing or extending a lesson's `README.md`, follow the existing lesson (01 or 02) as the template for tone, heading depth, and section ordering, and keep the outline in `outline-claude.md` as the source of truth for what subtopics that lesson must cover.
- Code snippets embedded in lesson content are illustrative only — there is no corresponding runnable project in this repo to keep them in sync with, so correctness is judged by whether they teach the concept clearly, not by executing them.
- Image references in lesson content point to that lesson's own `assets/` folder using relative paths (e.g. `assets/productcard_component_vs_instances.png`).


## Quy tắc vẽ sơ đồ minh hoạ (SVG)

- Luôn dùng nền trắng đặc (fill="#ffffff"), không để trong suốt.
- Đặt một <rect> phủ toàn bộ viewBox làm phần tử đầu tiên (sau <defs>).
- Vì cố định nền trắng, các màu chữ/viền/khung nên dùng mã hex cố định (không dùng biến theme tự đổi theo dark mode), để đảm bảo luôn tương phản tốt trên nền trắng.
- `viewBox="0 0 680 H"`, giữ nguyên chiều rộng 680 để khớp khung hiển thị; chỉ tính lại H theo nội dung + 40px lề dưới.
Không để bất kỳ khối/nhãn nào tràn ra ngoài `viewBox` hoặc đè lên nhau.
- Mũi tên dùng chung 1 <marker id="arrow"> khai báo trong <defs>, áp cho mọi <line>/<path> nối các khối.
- Đường nối rẽ nhánh dùng <path> dạng chữ L, không vẽ đường chéo xuyên qua khối khác.
- Giữ phong cách nhất quán giữa các sơ đồ trong cùng một cuộc trò chuyện/tài liệu (cùng bảng màu, cùng kiểu khung, cùng cỡ chữ).
